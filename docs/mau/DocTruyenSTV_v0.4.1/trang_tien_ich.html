Cấu hình API giọng đọc cao cấp

Tiện ích tích hợp sẵn Web Speech API (không giới hạn, miễn phí mặc định) làm cốt lõi; ngoài ra bạn có thể gắn thêm API Key từ các hãng công nghệ hoặc máy chủ cá nhân để có thêm lựa chọn giọng đọc tự nhiên.
Cảnh báo: Xếp hạng sao dựa trên đánh giá chủ quan

Số sao xếp hạng dưới đây (bao gồm cả mức 6 sao đặc biệt dành cho Google Gemini TTS) được đánh giá dựa trên quan điểm chủ quan của tác giả về độ tiện lợi, mức miễn phí và chất lượng trải nghiệm cá nhân, nên có thể khác với trải nghiệm thực tế của từng người. Khuyến khích bạn ưu tiên thử Web Speech API có sẵn hoặc tự trải nghiệm để chọn nguồn phù hợp nhất.

Lưu ý về sự cố trong quá trình sử dụng

Vì đây là dịch vụ miễn phí lấy từ bên thứ 3, đôi lúc hệ thống máy chủ của các nhà cung cấp hoặc Azure có thể bị quá tải (lỗi Request / Quota) hoặc do kết nối mạng kém khiến giọng đọc bị khựng, nhảy đoạn đọc.

Tiện ích đã có sẵn cơ chế tự động thử tải lại, nhưng nếu lỗi vẫn tiếp diễn, bạn chỉ cần tạm dừng khoảng 1 phút rồi bấm phát lại, hoặc chuyển tạm sang Web Speech API để đọc tiếp.

Microsoft Azure TTS đã được kiểm thử thực tế hoạt động ổn định (Đã test OK). FPT.AI vẫn được giữ tương thích cho khóa cũ với endpoint v5 nhưng FPT.AI Console đã ngừng cung cấp dịch vụ cá nhân từ ngày 06/07/2026 nên các khóa Free hết hạn mức có thể trả HTTP 429. Google Gemini TTS, Zalo AI, VNPT SmartVoice, Cartesia AI, ElevenLabs, Fish Audio, Viettel AI, Google Cloud TTS, VieNeu-TTS và nguồn API tùy chỉnh cần thêm khóa hoặc máy chủ thực tế để kiểm thử tiếp.

Nhóm 1: Gói Free (Không cần thẻ Visa)
Xếp theo số sao từ cao xuống thấp, sao bằng nhau xếp theo bảng chữ cái
1. Google Gemini TTS
Khuyến khích nên dùng Chưa test key
Miễn phí hàng ngày (reset theo giới hạn RPM/RPD, không tính phí tháng với Gmail thường), chất giọng biểu cảm, ngắt nghỉ tự nhiên theo ngữ cảnh truyện (Model mặc định: gemini-3.8-flash-lite-tts).
  1. Truy cập Google AI Studio và đăng nhập bằng tài khoản Gmail cá nhân (không yêu cầu thẻ thanh toán).
  2. Bấm nút Create API key, chọn hoặc tạo mới một dự án Google AI miễn phí rồi sao chép khóa vừa tạo.
  3. Mở cửa sổ nổi Đọc Truyện Cho STV > Nguồn giọng đọc > + Thêm Nguồn Đọc Mới > chọn Google Gemini TTS, dán API Key (giữ Model gemini-3.8-flash-lite-tts) rồi bấm Thêm.
Hoặc truy cập vào tài liệu chính thức này để xem chi tiết: Google Gemini Speech Generation Docs
2. Zalo AI TTS
Chưa test key
Cung cấp gói miễn phí hàng tháng dành cho nhà phát triển, có đủ giọng Nam/Nữ 3 miền Bắc - Trung - Nam, độ trễ tốt tại Việt Nam.
  1. Truy cập Zalo Developers (hoặc Zalo AI Solutions) và đăng nhập tài khoản Zalo.
  2. Tạo ứng dụng (App) hoặc dự án mới, bật API Text to Speech (Chuyển văn bản thành giọng nói) trong danh mục dịch vụ.
  3. Vào phần quản lý khóa của ứng dụng để sao chép API Key (apikey), rồi chọn Zalo AI TTS trong + Thêm Nguồn Đọc Mới để dán vào.
Hoặc truy cập vào tài liệu chính thức này để xem chi tiết: Tài liệu chính thức Zalo AI TTS (Text to Audio Converter)
3. VNPT SmartVoice
Chưa test key
Cấp 30.000 ký tự miễn phí/tháng cho giọng chuẩn 3 miền Việt Nam (tối đa 500 ký tự/lần gọi, phù hợp với cơ chế chia đoạn tự động của tiện ích). Yêu cầu tài khoản VNPT AI, không cần thẻ Visa.
  1. Đăng ký tài khoản tại VNPT SmartVoice hoặc VNPT AI Portal bằng email hoặc số điện thoại Việt Nam.
  2. Đăng ký sử dụng gói miễn phí dịch vụ Text to Speech (TTS) và tạo thông tin xác thực API.
  3. Sao chép đủ 3 giá trị: Access Token (JWT), Token-id và Token-key, sau đó chọn VNPT SmartVoice trong + Thêm Nguồn Đọc Mới để nhập cả 3 trường.
Hoặc truy cập vào tài liệu chính thức này để xem chi tiết: Tài liệu API chính thức VNPT SmartVoice
4. Cartesia AI
Chưa test key
Tặng 20.000 credits/tháng (~20.000 ký tự, ~27 phút audio), tốc độ phản hồi cực nhanh dưới 90ms với model sonic-3.6 hỗ trợ mã ngôn ngữ tiếng Việt (vi).
  1. Đăng ký tài khoản miễn phí bằng email tại Cartesia Playground (không cần thẻ tín dụng).
  2. Vào mục API Keys trên thanh menu, bấm tạo khóa mới và sao chép. Bạn có thể chọn thêm Voice ID trong mục Voices hoặc bỏ trống để tiện ích tự nạp danh sách giọng.
  3. Chọn Cartesia AI trong + Thêm Nguồn Đọc Mới, dán API Key và nhấn Thêm.
Hoặc truy cập vào tài liệu chính thức này để xem chi tiết: Cartesia TTS API Documentation
5. ElevenLabs
Chưa test key
Tặng 10.000 ký tự/tháng (~10 phút audio), giọng đọc có độ truyền cảm và ngắt nhịp cao với model đa ngôn ngữ tốc độ nhanh eleven_flash_v2_5.
  1. Đăng ký tài khoản bằng email tại ElevenLabs (không cần thẻ).
  2. Nhấp vào ảnh hồ sơ ở góc màn hình > chọn API Keys (hoặc mục Developers), tạo mới một API Key có quyền đọc Text-to-Speech và sao chép.
  3. Chọn ElevenLabs trong + Thêm Nguồn Đọc Mới, dán API Key (có thể nhập thêm Voice ID yêu thích hoặc bỏ trống dùng giọng mặc định) rồi nhấn Thêm.
Hoặc truy cập vào tài liệu chính thức này để xem chi tiết: ElevenLabs Text-to-Speech API Docs
6. Fish Audio
Chưa test key
Hỗ trợ tạo giọng đọc qua model s2.1-pro-free với hạn mức Free tier có giới hạn; có thể ghép thêm giọng cộng đồng thông qua Reference ID.
  1. Đăng ký tài khoản miễn phí tại Fish Audio.
  2. Mở mục quản lý API Keys trong tài khoản để tạo khóa mới (tùy chọn lấy Reference ID của giọng tiếng Việt ưng ý trên thư viện mẫu).
  3. Chọn Fish Audio trong + Thêm Nguồn Đọc Mới, dán API Key rồi nhấn Thêm.
Hoặc truy cập vào tài liệu chính thức này để xem chi tiết: Fish Audio TTS API Docs
7. Viettel AI TTS
Chưa test key
Tặng 50.000 ký tự một lần khi tạo tài khoản mới (giới hạn trải nghiệm ban đầu), hỗ trợ nhiều giọng đọc 3 miền khá rõ ràng.
  1. Đăng ký tài khoản tại Viettel AI bằng email hoặc số điện thoại Việt Nam (không cần thẻ).
  2. Kích hoạt dịch vụ Text to Speech trên bảng điều khiển, sau đó truy cập Quản lý Token Viettel AI để sao chép Token.

Nhóm 2: Cần thẻ Visa / Mastercard
Yêu cầu liên kết thẻ thanh toán quốc tế để kích hoạt tài khoản Cloud
1. Microsoft Azure TTS
Cần thẻ VISA Đã test OK
Giọng Azure (đặc biệt là giọng Hoài My và Nam Minh) cực kỳ mượt mà, ổn định. Microsoft tặng gói Free F0 lên tới 500.000 ký tự Neural/tháng. Bắt buộc có thẻ VISA/Mastercard để xác minh tài khoản chống spam.
  1. Truy cập Portal Azure để đăng ký tài khoản (cần thẻ thanh toán để xác minh danh tính).
  2. Gõ Speech Services vào thanh tìm kiếm trên cùng và bấm nút Create (Tạo mới) một tài nguyên.
  3. Lưu ý các thông số cấu hình:
    - Region: Nên chọn Southeast Asia (Đông Nam Á) để tải nhanh.
    - Pricing tier (Gói cước): Bắt buộc chọn Free F0 (Miễn phí). Chọn nhầm sang Standard S0 sẽ bị tính phí ngay!
  4. Đợi khoảng 1-2 phút khởi tạo xong, bấm Go to resource > chọn Keys and Endpoint ở menu bên trái.
  5. Copy KEY 1 và Location/Region (VD: southeastasia), chọn Microsoft Azure TTS trong + Thêm Nguồn Đọc Mới để dán vào và bấm Thêm.
Hoặc truy cập vào tài liệu chính thức này để xem chi tiết: Microsoft Azure Speech REST Docs
2. Google Cloud TTS
Cần thẻ VISA · Có rủi ro mất tiền Chưa test key
Hỗ trợ nhiều giọng đọc (Wavenet/Standard/Neural2) với hạn mức Free tier hàng tháng là 4.000.000 ký tự Standard/WaveNet hoặc 1.000.000 ký tự Neural2. Cảnh báo rủi ro mất tiền: Bạn bắt buộc phải bật Billing Account; nếu dùng vượt quá hạn mức miễn phí hàng tháng, Google sẽ tự động trừ tiền qua thẻ đã liên kết.
  1. Truy cập Google Cloud Console và thiết lập Billing Account bằng thẻ thanh toán quốc tế (nên đặt thêm Budget Alert cảnh báo chi tiêu).
  2. Bấm chọn Select a project ở thanh trên cùng và tạo một dự án mới (VD: Doc-Truyen-STV).
  3. Tìm dịch vụ Cloud Text-to-Speech API trên thanh tìm kiếm và bấm Enable (Bật).
  4. Vào menu APIs & Services > Credentials > Create Credentials > API key để tạo khóa (nên giới hạn khóa chỉ dùng cho API Text-to-Speech).
  5. Sao chép API Key, chọn Google Cloud TTS trong + Thêm Nguồn Đọc Mới để dán vào và bấm Thêm.
Hoặc truy cập vào tài liệu chính thức này để xem chi tiết: Google Cloud Text-to-Speech Documentation
Nhóm 3: Cài đặt cá nhân (Cá nhân hóa)
Dành cho máy chủ chạy cục bộ (Self-host) hoặc endpoint API tùy biến riêng
1. VieNeu-TTS (Chạy cục bộ trên máy cá nhân)
Cá nhân hóa · Miễn phí vô hạn Chưa test máy chủ
Mô hình tổng hợp tiếng Việt mã nguồn mở chạy hoàn toàn offline trên máy tính cá nhân của bạn (không phụ thuộc Internet, không giới hạn ký tự), giao tiếp qua máy chủ cục bộ chuẩn OpenAI Speech (/v1/audio/speech, model mặc định vieneu-v3-turbo).
  1. Tải mã nguồn VieNeu-TTS về máy cá nhân theo hướng dẫn cài đặt bằng Python / uv hoặc Docker từ trang GitHub chính thức.
  2. Khởi chạy máy chủ OpenAI Speech cục bộ (VD: uv run python -m apps.openai_speech) để mở cổng mặc định tại http://127.0.0.1:8000 (hoặc http://localhost:8000).
  3. Mở cửa sổ nổi > + Thêm Nguồn Đọc Mới > chọn VieNeu-TTS (Cục bộ), nhập địa chỉ máy chủ đang chạy rồi bấm Thêm.
Hoặc truy cập vào tài liệu chính thức này để xem chi tiết: GitHub VieNeu-TTS Chính Thức
2. Nguồn đọc khác (Khác · Tùy chỉnh API)
Cá nhân hóa · Nâng cao Chưa test API
Dành cho người dùng am hiểu kỹ thuật muốn tự kết nối với các dịch vụ REST API hoặc máy chủ trung gian tự xây dựng bằng cách tự định nghĩa đường dẫn, tiêu đề và khuôn mẫu JSON.
  1. Nhập Đường dẫn (API URL) của nguồn đọc và chọn phương thức POST hoặc GET.
  2. Tại Headers JSON, nhập đối tượng JSON chứa khóa xác thực hoặc kiểu dữ liệu theo tài liệu của máy chủ đích.
    Ví dụ:
    {"Authorization": "Bearer mã_bí_mật_của_bạn"}
  3. Tại Body Template, chèn biến {{van_ban}} vào đúng vị trí chứa đoạn truyện cần đọc.
    Ví dụ:
    {"text": "{{van_ban}}", "voice": "mặc_định"}
  4. Tại Audio Path, điền đường dẫn thuộc tính tới URL/Base64 âm thanh nếu API trả về JSON (VD: data.audioUrl), hoặc bỏ trống nếu API trả trực tiếp tệp âm thanh (Audio Blob).
