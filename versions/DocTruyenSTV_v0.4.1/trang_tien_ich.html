Cấu hình API Giọng đọc Cao cấp

Việc sử dụng API Key giúp tiện ích truy cập trực tiếp vào máy chủ của các hãng công nghệ lớn, mang lại giọng đọc tự nhiên, ngắt nghỉ như người thật và tốc độ tải cực nhanh.
Lưu ý về sự cố trong quá trình sử dụng

Vì đây là dịch vụ miễn phí lấy từ bên thứ 3, đôi lúc hệ thống máy chủ của FPT hoặc Azure có thể bị quá tải (lỗi Request / Quota) hoặc do kết nối mạng kém khiến giọng đọc bị khựng, nhảy đoạn đọc.

Tiện ích đã có sẵn cơ chế tự động thử tải lại, nhưng nếu lỗi vẫn tiếp diễn, bạn chỉ cần tạm dừng khoảng 1 phút rồi bấm phát lại, hoặc chuyển tạm sang Web Speech API để đọc tiếp.

Vì hiện tại chức năng này vẫn đang thử nghiệm nên trong quá trình có thể xảy ra lỗi, hoặc đột nhiên ngày đẹp trời lại bị lỗi và không phát được.

1. Dành cho FPT.AI
Khuyên dùng
FPT cung cấp 100.000 ký tự miễn phí mỗi tháng (Đủ để đọc vài chục chương truyện). Giọng đọc rất mượt, chuẩn tiếng Việt và hệ thống duyệt tự động ngay lập tức.
  1. Truy cập Console FPT.AI và tiến hành đăng ký tài khoản (hoặc đăng nhập bằng Google).
  2. Hệ thống sẽ yêu cầu bạn Tạo một Dự án (Project) mới. Điền tên bất kỳ (Ví dụ: Đọc Truyện) rồi ấn tạo.
  3. Tại màn hình chính của dự án, cuộn xuống tìm thẻ Text to Speech và Bấm gạt công tắc ở góc phải cho thẻ sáng màu xanh lên.
  4. Một bảng xác nhận hiện ra yêu cầu bạn điền Tên Khóa (Key name). Nhập STV hoặc tên bất kỳ rồi bấm Tạo.
  5. Nhìn sang cột menu bên trái màn hình, nhấp vào mục API Keys.
  6. Tìm dãy mã vừa được tạo, bấm vào Biểu tượng Copy (Hình 2 tờ giấy) ngay bên cạnh.
  7. Mở lại bảng Đọc Truyện Cho Sáng Tác Việt > Chuyển sang Tab Cài đặt > Chọn Nguồn giọng đọc là FPT.AI > Dán dãy mã vào ô trống và bấm Lưu API Key.
2. Dành cho Microsoft Azure TTS
Cần thẻ VISA
Giọng Azure (đặc biệt là giọng Hoài My) được đánh giá là tự nhiên nhất thế giới. Microsoft tặng gói F0 miễn phí lên tới 500.000 ký tự/tháng. Tuy nhiên, rào cản là bạn bắt buộc phải có thẻ VISA/Mastercard để xác minh danh tính chống spam.
  1. Truy cập Portal Azure để đăng ký tài khoản (Hệ thống yêu cầu thêm thẻ nhưng sẽ không trừ tiền nếu làm đúng bước 3).
  2. Tại màn hình chính, gõ vào thanh tìm kiếm trên cùng cụm từ Speech Services và nhấp vào kết quả.
  3. Bấm nút Create (Tạo mới) một tài nguyên. Lưu ý các thông số:
    - Region: Nên chọn Southeast Asia (Đông Nam Á) để load nhanh.
    - Pricing tier (Gói cước): Bắt buộc phải chọn Free F0 (Miễn phí). Chọn nhầm sang Standard S0 sẽ bị trừ tiền!
  4. Nhấn Create và đợi khoảng 1-2 phút để khởi tạo máy chủ. Sau khi xong, bấm Go to resource.
  5. Nhìn sang cột menu bên trái, tìm và nhấp vào mục Keys and Endpoint.
  6. Copy KEY 1 và Location/Region (VD: southeastasia) dán vào ô thiết lập tương ứng trong tiện ích.
3. Dành cho Google Cloud TTS
Cần thẻ VISA
Giọng đọc Google Cloud (đặc biệt các giọng Wavenet/Standard) rất đa dạng và đọc rất hay. Google cung cấp hạn mức miễn phí lên tới 1 triệu ký tự/tháng đối với giọng Standard, nhưng yêu cầu liên kết thẻ thanh toán để thiết lập Billing Account.
  1. Truy cập Google Cloud Console và đăng nhập bằng tài khoản Google. Tiến hành liên kết thẻ thanh toán nếu chưa có.
  2. Tại thanh trên cùng, bấm chọn Select a project và tạo mới một dự án (VD: Doc-Truyen-STV).
  3. Trên thanh tìm kiếm, gõ Cloud Text-to-Speech API và chọn nó. Bấm nút Enable (Bật).
  4. Truy cập menu bên trái: APIs & Services > Credentials.
  5. Nhấn Create Credentials trên cùng và chọn API key.
  6. Copy API key vừa tạo, mở lại bảng Đọc Truyện Cho Sáng Tác Việt > Tab Cài đặt > Chọn nguồn Google Cloud TTS, dán khóa vào ô trống và bấm Lưu API Key.
4. Dành cho Nguồn Khác (Tùy chỉnh API)
Nâng cao
Phần này dành cho những bạn muốn tự kết nối với các nguồn giọng đọc khác trên mạng (Ví dụ: Zalo TTS, Viettel AI...) hoặc máy chủ do bạn tự tạo. Bạn chỉ cần "dạy" cho tiện ích biết cách giao tiếp với nguồn đọc đó.
  1. Nhập Đường dẫn (API URL) của nguồn đọc. Thường nhà cung cấp sẽ cho bạn biết nên chọn GET hay POST.
  2. Tại Headers JSON, đây giống như "thẻ căn cước" để chứng minh bạn có quyền sử dụng (Ví dụ: mã xác thực API Key).
    Ví dụ:
    {"apikey": "mã_bí_mật_của_bạn"}
  3. Tại Body Template, đây là nơi bạn gửi nội dung cho họ đọc. Bạn hãy tạo sẵn một khung mẫu, tiện ích sẽ tự động chèn đoạn văn bản đang đọc vào đúng vị trí có chữ {{van_ban}}.
    Ví dụ:
    {"text": "{{van_ban}}", "voice": "hn-quynhanh", "speed": 1}
  4. Tại Audio Path, sau khi hệ thống kia đọc xong, họ sẽ trả kết quả về. Bạn cần chỉ đường cho tiện ích biết cái "Link âm thanh" nằm ở đâu trong gói kết quả đó.
    Ví dụ: Nếu kết quả trả về là {"data": {"audioUrl": "https://..."}}, bạn điền data.audioUrl
    Lưu ý: Nếu hệ thống kia trả về trực tiếp một file âm thanh nghe được luôn (Audio Blob), hãy Bỏ trống ô này.
