Hướng dẫn lấy API Key (Miễn phí)
(Có thể có lỗi trong quá trình sử dụng)

Sử dụng API Key giúp giọng đọc mượt mà, ngắt nghỉ như người thật và không bị lỗi vặt.

1. Dành cho FPT.AI (Khuyên dùng)

FPT cung cấp 100.000 ký tự miễn phí mỗi tháng, đủ để bạn đọc vài chục chương truyện. Hệ thống đã được tiện ích tích hợp tự động, bạn chỉ cần lấy Key dán vào là chạy.

Các bước thao tác cực nhanh trên Console FPT.AI:
  1. Truy cập Console FPT.AI và tạo tài khoản / đăng nhập.
  2. Tại màn hình chính, tìm thẻ Text to Speech và bấm gạt công tắc ở góc phải cho nó chuyển sang màu xanh.
  3. Hệ thống sẽ hiện bảng hỏi xác nhận bật API, sau đó yêu cầu bạn điền tên khóa (Key name, VD: STV). Điền xong bấm nút tạo.
  4. Khóa sẽ được tự động tạo. Bạn chỉ cần nhìn sang menu bên trái, bấm vào mục API Keys.
  5. Bấm vào biểu tượng Copy (hình 2 tờ giấy) cạnh mã Key bạn vừa tạo.
  6. Mở tiện ích Auto Đọc STV > Tab Cài đặt > Chọn nhóm FPT.AI > Dán mã vào ô > Bấm Lưu API Key.

2. Dành cho Microsoft Azure TTS

Giọng Azure được đánh giá là tự nhiên nhất thế giới. Microsoft tặng gói F0 miễn phí 500.000 ký tự/tháng. Tuy nhiên, quá trình đăng ký yêu cầu thẻ VISA/Mastercard để xác minh chống spam.

  1. Truy cập Portal Azure để đăng ký tài khoản.
  2. Tìm dịch vụ Speech Services và tạo mới một tài nguyên (Resource).
  3. Chọn Pricing tier là Free F0.
  4. Sau khi tạo xong, vào mục Keys and Endpoint.
  5. Copy KEY 1 (dán vào ô API Key) và Location/Region (VD: southeastasia - dán vào ô Region của tiện ích).
